# Thick Slice — web sitesi

Detroit tarzı kare pizza sitesi. Statik dosyalar; sunucu gerekmez.

## GitHub Pages ile yayınlama
1. Bu klasörün içeriğini deponun köküne yükle.
2. Settings → Pages → Source: `main` / `root` → Save.
3. Birkaç dakika içinde site yayında olur.

`.nojekyll` dosyası `_ds/` klasörünün yayında görünmesi için gereklidir — silme.
